## 这是什么

ESXi Control 是一个 Home Assistant 自定义集成。它直连你的 ESXi 主机（或 vCenter），
把**主机、每一台虚拟机、每个数据存储、许可证**全部映射成 HA 里的实体 ——
于是虚拟化平台不再是"HA 之外另一个需要单独登录的系统"，而是仪表盘上普普通通的一部分：

- 手机上就能给某台虚拟机开机、做快照、重启；
- 直接看到每台机器的 CPU、内存、磁盘、快照数、Tools 状态；
- 点开设备页的「访问」，浏览器里直接出现那台机器的**远程桌面画面**，键盘鼠标都能用；
- 甚至能**进到客户机里面**：看进程、传文件、改注册表、开终端；
- 每台机器的画面还能贴到仪表盘上当**屏幕墙**，一眼扫过全场状态。

它不是监控面板的替代品，而是把"监控 + 控制 + 远程运维"三件事塞进同一个地方。

集成负责"把能力做出来"，但它给的是**标准化的 HA 实体** —— 想好用还得自己在界面上搭。
**房间精灵**就是为了替你搭这一步而写的：

| | 只用集成 | 集成 + 房间精灵卡片 |

| 配置量 | 卡片里要一个个挑实体，几十上百个 | **只写一个聚合实体**，其余全自动识别 |
| 界面 | 一堆实体卡 / 自行排版 | **一张卡三页**：主机 / 虚拟机 / 屏幕墙 |

# 与房间精灵卡片结合：这才是完整形态

> 🔗 **房间精灵**：https://github.com/chjspp520/room-elves-card

**房间精灵**是同一作者的另一件作品 —— 一张 Home Assistant 前端自定义卡片（纯前端，无后端）。
它内置的 **ESXi 虚拟化卡片（`type: esxi`）**就是为这个集成**量身定做**的：
卡片的全部数据来自本集成输出的聚合实体（默认 `sensor.esxi_all_entities`），
全部操作走的就是本集成注册的实体与服务 —— 你在卡片上按下的每一个按钮，
和你在 HA 里直接调用 `button.press` / `switch.turn_on` 是**同一条路径**。

**反过来也成立**：卡片**不能独立工作**。没装本集成时它不会崩，只会提示
`ESXi 聚合实体不存在或未加载：sensor.esxi_all_entities`。

## 装上之后拿到什么

### 页面一：主机

从上到下七个区块，顺序刻意按"**先看现状 → 再动手 → 最后才看参数与明细**"排列：

| 区块 | 内容 |
|---|---|
| ① **事件日志** | 常显最新一条 ESXi 事件，**点开看全部** |
| ② **主机状态** | CPU / 内存两条进度条（**点它看近期曲线**）；下方信息网格：运行时长 / 构建版本 / 维护模式 / 数据存储 / 连接状态 / 整体状态；右上角是许可证状态 |
| ③ **批量操作** | 全部开机 / 关机 / 重启 / 强制重启 / 快照 / 截图开关 —— 一键搞定全场 |
| ④ **系统管理** | 主机关机、重启、维护模式开关、刷新服务清单（不支持的操作会自动置灰） |
| ⑤ **主机配置** | 数据刷新间隔 / 聚合刷新间隔 / 截图间隔 / 批量分组 / 电源策略，以及 **NTP / SSH / ESXi Shell 三个服务的启停 + 启动策略 + 重启**，末尾是「同步（重载集成）」 |
| ⑥ **主机诊断** | 硬件健康 / 服务状态 / 网络拓扑 / 防火墙规则 / 登录会话 / 存储拓扑 —— 六项都是"摘要 state + 明细属性"，**点开气泡铺开看** |
| ⑦ **数据存储** | 各数据存储的容量与状态，点开看明细 |

### 页面二：虚拟机

- 顶部有**状态过滤胶囊**（全部 / 运行中 / 已停止）+ **名称搜索框**，两者叠加生效；
- 每台虚拟机一张卡：电源状态徽标 + IP，CPU / 内存指标（**优先用活跃内存**，点指标看曲线），
  六项元信息（系统 / 磁盘 / 快照 / 运行时长 / Tools / 状态，点开**详细信息气泡**）；
- 操作行：开机 · 关机 · 挂起 · 唤醒 · 重启 · 强制重启 · 截图 · 画面；
- 其余全部收进「**更多**」气泡（有快照时按钮带提示色）：快照五件套、优雅关机、关闭电源、
  待机、Tools 升级、弹出光盘、合并磁盘、凭据校验、随主机自启、网卡开关 ——
  **每一项都按电源状态与可用性置灰，点下去会告诉你为什么不能点**；
- 「画面」打开居中画面窗：teal 标题栏显示虚拟机名 + 截图时刻 + 全屏按钮，标题栏 sticky；
- 关机的机器默认折叠成一行，列表不会拉得老长。

### 页面三：屏幕墙

- 一行 2~4 格、最多 8 格，虚拟机超过 20 台自动换成一行 4 个；
- 每格 = 实时画面 + 状态条（状态点 / 名称 / 截图时刻 / 截图开关 / 全屏）；
- 工具栏：「选择上墙的虚拟机」（气泡多选，按钮显示已选台数）+ 截图间隔 + 刷新；
- 画面不可用时**给明确原因**：`虚拟机已关机` / `自动截图已关闭` / `暂无画面（等待截图）`；
- 取图走集成的 `image.*` 实体（HA 官方 image 代理），**不自造缓存参数、不额外轮询**。

### 交互细节

- 三个选项卡支持**鼠标拖动 / 触摸左右滑**切页（跟手 + 松手吸附 + 首尾阻尼），
  选项卡高亮跟着滑动走；
- **卡片高度只由「主机」页决定**，另两页内部滚动 —— 切页时高度不跳；
- 自带 **3 秒值级刷新**：只写文本 / 进度条宽度 / 类名，逐项脏检查，
  **只有结构签名变化才重建 DOM**；订阅刻意排除 `image.*`（它的 state 每 2 秒一变）；
- 实时值一律直接读 `hass.states`，**不等聚合实体的刷新周期** —— 点了开关，界面立刻动。

## 怎么用

**安装卡片**：HACS → 前端 → 右上角三点 → **自定义存储库** →
`https://github.com/chjspp520/room-elves-card`，类别选 **Lovelace**。

```yaml
# 最省事：一张常显卡片，只给聚合实体
type: custom:room-elves-card
standalone_type: esxi
entity: sensor.esxi_all_entities
name: 虚拟化
```

```yaml
# 做成点击弹出的独立面板，只显示指定设备
type: custom:room-elves-card
tap_action:
  action: card
  card:
    type: esxi
    name: ESXi 主机
```

| 常用参数 | 说明 |
|---|---|
| `entity` | 聚合实体，默认 `sensor.esxi_all_entities` |
| `name` / `icon` | 卡片标题（默认「ESXi 虚拟化」）/ 头部图标（默认 `mdi:server`） |
| `hosts` / `vms` | 只保留这些**主机** / **虚拟机**（按设备名；不配 = 全部） |
| `exclude` | 排除这些设备（适合排掉承载许可证的兜底设备「ESXi 统计」） |
| `default_vm` | 「屏幕墙」页默认上墙的虚拟机（不配 = 自动挑一台运行中的） |
| `show_screen` / `show_refresh` / `show_sync` | 是否生成屏幕墙页 / 头部刷新按钮 / 同步行 |
| `confirm_power_off` | `false` 时关机不再二次确认 |
| `width` / `popup_width` / `popup_position` | 卡片宽度 / 独立弹窗宽度（默认 760px）/ 弹窗位置 |

> 💡 卡片按「**设备名 + 中文短名**」识别角色（而不是按 `entity_id` 后缀），
> 所以中文名的虚拟机照样认得，也不用担心以后改 id。

# 核心亮点

### 1. 完整的实体树，中文状态，短 `entity_id`

一台主机一个设备、每台虚拟机一个设备，实体按角色自动生成：

- 虚拟机**电源状态是中文的**：`运行中` / `已关机` / `挂起中`；
- 默认启用**短 `entity_id`**（`switch.ha_power` 而不是一长串拼音），写自动化不用复制长 id；
- 显示名仍是「设备名 + 中文短名」，界面上完全看不出 `entity_id` 被改过。

### 2. 真能控：从电源到快照到网卡

- **关机分三档**：`关机`（装了 Tools 走优雅关机，否则硬关）、`优雅关机`（`ShutdownGuest`）、
  `关闭电源`（硬断电）；
- **重启同理**：`重启` 智能选择热重启 / 硬重置，`强制重启` 一律硬重置；
- **快照全家族**：创建、删除（全部 / 最早 / 最新）、还原；
- **网卡热插拔**：按 MAC 生成开关，开机状态下也能断开 / 连接某块网卡；
- **光盘**：上传本地 ISO，或让集成把一个目录**自动打包成 ISO** 挂载；
- **随主机自启**：逐台设置，外加主机侧总开关。

开关类实体带**乐观状态**：提交后界面立刻显示期望值并快速催刷新，长时间没追上就回退真实值。

### 3. 批量操作，还带节奏控制

全部开机 / 全部关机 / 全部关闭电源 / 全部重启 / 全部强制重启 / 全部快照 / 全部截图开关。
逐台复用单台逻辑（装了 Tools 的优雅关机、没装的硬关机，行为一致）。
想慢一点就给 `text.batch_grouping` 填 `"3,10"` —— **每 3 台一批、批间等 10 秒**。
全过程实时写进 `sensor.operation_log`（进度 + 滚动日志）。

### 4. 免装客户端的网页远程控制台

内置**同源**网页控制台（WMKS / VMRC 自适应，走 ESXi 自己的 WebSocket）：
不用装 VMware Remote Console，不用放行自签证书，点开就用。

| | |
|---|---|
| 键盘 | 桌面端直接打字；触摸设备有**物理键盘桥**（Esc / Tab / F1~F12 / 方向键 / 普通字符） |
| 虚拟键盘 | 功能键自动折行、可调透明度、移动端支持"画面在上键盘在下"的分栏 |
| 虚拟鼠标 | **可拖动的鼠标指针**：拖它 = 移动客户机鼠标本身（1:1 绝对映射），点它 = 左键单击；另有左键 / 右键 / 双击 / 滚轮 / 拖动锁 |
| 触摸手势 | 轻点 = 单击、双击 = 双击、两指点一下 = 右键、双指滑 = 滚轮、**长按 ≈ 0.5 秒 = 右键** |
| 光盘抽屉 | 上传 ISO 挂载，或让集成把目录自动打包成 ISO |
| 文件系统抽屉 | 右侧半透明抽屉内嵌来宾页面，**关抽屉不中断画面** |
| 移动端 | 悬浮菜单 + 可拖动小圆钮、伪全屏退路、软键盘跟随、屏蔽浏览器右键菜单 |

**安全模型**：链接按**虚拟机粒度**用 HA 官方的 `async_sign_path` 签 `authSig`，24 小时有效；
拿到链接只能访问那**一台**虚拟机；ESXi 的账号密码**永远不会出现在页面或前端代码里**。

### 5. 进到客户机里面干活（双通道）

| 通道 | 前提 | 能做什么 |
|---|---|---|
| **VMware Tools** | 开机 + Tools 运行 | 列进程、启停程序、列目录、建 / 删、上传 / 下载、查注册表（Windows） |
| **SSH** | 配了 SSH 账号 | 进程、文件、SFTP 上传下载、**终端（执行命令并看输出）** |

通道自动择优；页面顶栏「系统连接设置」可自助填账号、校验指纹、**测试连接** ——
**没配凭据也能打开页面**。同样的能力注册成了 11 个 HA 服务，返回结构化结果。

> 终端用的 `exec` 刻意**不注册成服务**（只在页面里开放）：那等于在客户机里开一个任意命令入口。

### 6. 网页里就能建虚拟机、改配置

主机级**虚拟机管理页**：浏览清单、**新建**（空白 / 按现有虚拟机配置克隆）、
**改配**（CPU / 内存 / 加磁盘 / 加改网卡）、**磁盘模式**、**模板开关**、**删除**。
危险操作都有二次确认，所有写操作都记在 HA 日志里。

### 7. 每台机器一张"屏幕墙"

打开某台虚拟机的截图开关，集成按间隔（2~600 秒，默认 15 秒）抓图生成 `image` 实体。
画面走 ESXi 的 `/screen`，**不需要 Tools、不需要登录态**，可以贴成屏幕墙，也可以点开看大图 / 全屏。

### 8. ESXi 的事件，直接进 HA 的自动化

每 15 秒读一次 ESXi 事件收集器：最新 20 条进传感器属性，**每条新事件同时派发到 HA 事件总线**
（`esxi_control_event`）并写进日志簿。"虚拟机异常关机""主机进入维护模式"可以直接触发自动化。

### 9. 一键断掉所有远程入口

`switch.esxi_remote_desktop` 是浏览器侧所有入口的**总闸**。关掉立刻：
清空所有设备的「访问」链接 → 控制台 / 来宾 / 管理页一律 403 →
**正在运行的控制台 WebSocket 被逐个关闭**。需要临时收紧权限时，一个开关就够。

# 三分钟上手

**1. 安装集成**

HACS → 集成 → 右上角三点 → **自定义存储库** → `https://github.com/chjspp520/esxi_control`
（类别 Integration）→ 搜索 **ESXi Control** 下载 → **重启 HA**。
手动安装：把 `esxi_control` 目录放进 `<config>/custom_components/` 后重启 HA。
依赖 `pyvmomi` / `pycdlib` / `asyncssh` 由 HA 自动安装。

**2. 添加并勾选监控项**

设置 → 设备与服务 → 添加集成 → **ESXi Control** → 填主机地址、端口（443）、账号密码
（自签证书保持 `verify_ssl` 关闭）。四个开关（主机 / 数据存储 / 许可证 / 虚拟机）默认全开。

**3. 装一张房间精灵卡片**（强烈建议）

见[与房间精灵卡片结合](#与房间精灵卡片结合这才是完整形态)，填 `entity: sensor.esxi_all_entities` 即可。

**4. 按需微调**

| 想做什么 | 怎么做 |
|---|---|
| 数据更新更快 / 更省 | 调 `number.update_interval`（默认 45 秒） |
| 截图更密 / 更稀 | 调 `number.screenshot_interval`（默认 15 秒） |
| 批量操作慢一点 | 给 `text.batch_grouping` 填 `"3,10"` |
| ESXi 里新增 / 删了虚拟机 | 点 `button.sync`（同步实体清单） |
| 想立刻看到最新值 | 卡片头部「立即刷新数据」或调 `esxi_control.refresh` |
| 想做自动化 | 监听 `esxi_control_event`，或直接 `button.press` / `switch.turn_on` |

<summary><b>常见问题（点开查看）</b></summary>

| 现象 | 先看这里 |
|---|---|
| 实体全不可用 | 地址 / 账号变了？`verify_ssl` 开着而证书是自签的？改完点 `button.sync` |
| 间隔改了没变快 | 数据刷新由轮询触发，看 `number.update_interval` 的 `effective` 属性 |

| 来宾操作失败 | VM 开机且 Tools 运行中？Windows 域账号要写 `DOMAIN\user` |

</details>

<details>
<summary><b>需要知道的限制（点开查看）</b></summary>

1. ESXi 里新增 / 删除 / 改名虚拟机后，需要点 `button.sync` 才会同步实体清单（集成不自动增删）。
2. 删除实体是从注册表**永久移除**；内置三道防误删守卫（ESXi 不可达时只新增不删除）。
3. 「强制重启」是硬重置，未落盘的数据会丢。
4. 来宾注册表只在 **Windows + VMware Tools** 下可用；终端 / `exec` 只在 **SSH 通道**下可用。
5. 控制台 / 来宾 / 管理页的链接 24 小时有效，拿到即可访问对应虚拟机，请妥善保管。
6. 操作日志只在内存里，HA 重启即清空。

</details>
